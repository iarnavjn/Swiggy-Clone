# 🍔 Swiggy Clone

A responsive **Swiggy Landing Page Clone** built using **HTML, CSS, and JavaScript**. This project recreates the look and feel of Swiggy's homepage with a modern UI, responsive layout, and basic interactive functionality.

## 📌 Features

- 🍕 Responsive landing page
- 📍 Delivery location input
- 🔍 Search bar with JavaScript functionality
- 🎨 Modern Swiggy-inspired UI
